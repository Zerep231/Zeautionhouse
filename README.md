# ZeAuctionHouse

A lightweight, secure, and optimized Auction House plugin for Paper 1.21.1+. 
**No Vault dependency, no virtual economy.** Players trade with real in-game items like Diamonds or Emeralds!

## 🌟 Features
- **No Vault Needed:** Uses physical items as currency.
- **Optimized & Lightweight:** Super small `.jar` size.
- **Marketplace GUI:** List, browse, buy, and cancel items directly in an intuitive GUI.
- **Builder Shop:** Buy building materials in bulk.
- **Delivery Mailbox:** Safely holds items when players are offline.
- **Database Support:** Fully supports SQLite and MySQL.
- **Multi-language:** English (`en`) and Vietnamese (`vi`).

## 📥 Download & Installation
1. Go to the [Releases](https://github.com/Zerep231/Zeautionhouse/releases) page to download the `.jar` and Source Code.
2. Place the JAR file into your server's `plugins/` folder.
3. Restart your server.

## 🎮 Commands
- `/ah` — Open the main Auction House menu.
- `/ah sell` — Open the Sell GUI.
- `/ah claim` — Collect items from your delivery mailbox.
- `/ah shop` — Open the Builder Shop.
- `/ah mylistings` — View and cancel your listings.
- `/ah reload` — Reload configuration (Admin).
